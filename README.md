# Точки разногласий

Интерактивный опрос из 30 спорных утверждений для дебатов с друзьями.

- ответы и прогресс хранятся только в браузере;
- участник получает переносимый код с именем и 30 ответами;
- режим организатора сравнивает несколько участников, ранжирует поляризующие темы и экспортирует CSV;
- backend, аналитика и внешние зависимости не используются.

Сайт: https://pashkinzon.github.io/debate-night/
